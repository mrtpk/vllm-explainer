Example basics page: key-value stores

BeginnerLearn the basicsabout 1 min read

Code version: vLLM @ 3e44c0d · 2026-10-22

Before you read

You do not need to read other pages first.

In one sentence

A KV store keeps each value under a key, so you can get the value back with the same key.

The idea#

Plain explanation of the idea, in short sentences. Define each new term at its first use.

An everyday comparison. A coat check gives you a ticket for your coat. The ticket is the key, and the coat is the value. The comparison stops here: a coat check has one coat per ticket, but a store can replace the value under a key.

The picture#

Read the diagram from left to right. Each box is one part. The colour of an arrow shows the part that sends the data.

Deep dive#

Deep dive

Exact data layout

Full detail for study: types, sizes, layout, the algorithm as a numbered list, edge cases, and a worked example with real numbers.

  1. Step 1. The store computes a hash of the key.
  2. Step 2. The hash selects a slot.

What can go wrong#

  • Two keys, one slot. Two keys can give the same slot. The store must keep both values.

Why it matters. One sentence on the effect for the reader.
